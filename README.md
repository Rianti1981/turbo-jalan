# Turbo Jalan

Game balap mobil 2D ringan untuk Android. Dibangun sebagai aplikasi Android WebView dan APK debug dibuat otomatis lewat GitHub Actions.

## Build APK
1. Buka tab **Actions**.
2. Pilih workflow **Build Android APK**.
3. Klik **Run workflow** (atau tunggu build otomatis setelah push).
4. Setelah selesai, unduh artifact **Turbo-Jalan-debug-APK**.

APK debug dapat dipasang di perangkat Android dengan mengizinkan instalasi dari sumber yang dipilih.

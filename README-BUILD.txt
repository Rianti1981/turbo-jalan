TURBO JALAN — proyek Android WebView

Proyek ini membungkus game HTML5 menjadi aplikasi Android.

Build otomatis:
1. Buka tab Actions pada repository.
2. Pilih workflow Build Android APK.
3. Klik Run workflow.
4. Setelah selesai, unduh artifact Turbo-Jalan-debug-APK.

Game berjalan offline dari assets/index.html.
